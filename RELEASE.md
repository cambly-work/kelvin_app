# Выпуск Kelvin

## Подготовка

1. Обновите `CFBundleShortVersionString` и увеличьте `CFBundleVersion` в `Info.plist`.
2. Добавьте описание изменений в `docs/notes.html`.
3. Пройдите [проверки перед выпуском](QA.md).
4. Подготовьте сертификат Developer ID Application, профиль `notarytool`
   и существующий приватный ключ подписи обновлений.

Ключи и пароли хранятся вне репозитория. Новую пару ключей создают при первоначальной
настройке канала обновлений, а не перед каждым выпуском.

## Сборка

Замените значения примера данными релизной машины:

```sh
DEVID_APP="Developer ID Application: Your Name (ABCDE12345)" \
AC_PROFILE="kelvin-notary" \
DOWNLOAD_BASE="https://trykelvin.com" \
SPARKLE_ED_KEY_FILE="/secure/path/to/update-key.txt" \
STYLE_DMG=1 \
./release.sh
```

`SPARKLE_ED_KEY_FILE` принимает экспортированный ключ или файл с полями
`PRIVATE_KEY` и `PUBLIC_KEY`. Для файла без публичного ключа задайте
`SUPUBLIC_ED_KEY` отдельно. Скрипт встраивает публичный ключ в `Info.plist`
собранного приложения и повторно подписывает бандл.

Team ID извлекается из `DEVID_APP` и подставляется в приложение и privileged helper
на время сборки. Исходные файлы восстанавливаются при завершении скрипта.

Скрипт собирает приложение, запускает тесты, подписывает компоненты, создаёт DMG
и ZIP для обновления, формирует `docs/appcast.xml` и выполняет нотаризацию,
если заданы `DEVID_APP` и `AC_PROFILE`.

Без этих параметров можно собрать локальный пакет, но он не будет нотаризован.
Сборка с Developer ID требует ключей подписи обновлений.

## Проверка и публикация

Для версии `0.9.0`:

```sh
codesign --verify --deep --strict Kelvin.app
xcrun stapler validate Kelvin-0.9.0.dmg
xmllint --noout docs/appcast.xml
shasum -a 256 Kelvin-0.9.0.dmg Kelvin-0.9.0.zip
```

Проверьте установку на чистой системе и обновление с предыдущего выпуска.
Отдельно проверьте работу установленных хелперов после обновления.

Сначала загрузите DMG и ZIP на хостинг, затем опубликуйте заметки к выпуску
и appcast. URL архива в appcast должен совпадать с адресом опубликованного ZIP.
Не меняйте архив после вычисления его подписи.
