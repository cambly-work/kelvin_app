# Kelvin — чек-лист предрелизного QA

Запускайте `./test/run-tests.sh` и `./typecheck.sh` для текущей версии.
Результаты конкретного прогона фиксируйте в описании выпуска с моделью Mac,
версией macOS и номером сборки. Этот список не подтверждает прохождение проверок.

Ручные проверки выполняются на чистой системе или под новым пользователем.
**AS** — Apple Silicon, **Intel** — Intel Mac.

## 0. Матрица окружений (минимум для релиза)
Прогнать ключевые разделы хотя бы на одной машине каждого типа — поведение SMC/IOKit/строки меню расходится.

- [ ] **AS-ноутбук** (MacBook с батареей) — основной сценарий использования.
- [ ] **Intel-ноутбук** (если доступен) — SMC-ключи и BCLM ведут себя иначе.
- [ ] **Десктоп без батареи** (Mac mini/Studio/iMac) — строка меню должна уходить в CPU-режим, не показывать фейковый заряд.
- [ ] **Mac с «чёлкой»** (notch) — строка меню/комбо-вид не должны обрезаться.
- [ ] **Внешний дисплей** (не-Retina) — чёткость глифов/комбо-картинки, читаемость.
- [ ] Светлая **и** тёмная тема (template-иконки тинтуются корректно).

---

## 1. Сборка, подпись, нотаризация (release.sh)
- [ ] `./build.sh` — зелёный, собирает app **и** демон `kelvin-fand`.
- [ ] `./test/run-tests.sh` — зелёный (юнит + i18n-покрытие). *Гейт в `release.sh`.*
- [ ] Bundle id для релиза **доменный** (не `com.local.*`) — иначе Developer ID + нотаризация не пройдут.
- [ ] `codesign --verify --strict` без ошибок; hardened runtime включён.
- [ ] Entitlements минимальны (сейчас только `apple-events`); **если добавится микрофон/экран — добавить usage-strings в Info.plist** (иначе краш под hardened runtime).
- [ ] `notarytool submit --wait` → **Accepted**; `stapler staple` на DMG прошёл.
- [ ] **Fresh-install на чистом Mac** (или новый пользователь): двойной клик DMG → перетащить → запуск **без** «приложение повреждено» / без обхода Gatekeeper.
- [ ] Gatekeeper: первый запуск показывает штатный диалог разработчика, не «неустановленный разработчик».

## 2. Первый запуск / онбординг
- [ ] Онбординг показывается один раз; повторный запуск его не повторяет.
- [ ] Иконка появляется **только** в строке меню (нет иконки в Dock).
- [ ] «Запускать при входе» включается/выключается (LoginItem / SMAppService), переживает перезагрузку.
- [ ] Язык: «Система» подхватывает локаль; ручной выбор ru/uk/en/pt применяется к меню и панели сразу.

## 3. Разрешения (TCC) — запрашиваются в контексте, отказ не ломает app
- [ ] **Уведомления** — при первом срабатывании алерта или из Настроек→Уведомления→«Отправить тест»; отказ → алерты молча не шлются, без краша.
- [ ] **Универсальный доступ** (Accessibility) — для авто-раскладки/сниппетов; без него фича выключена, app живёт.
- [ ] **Bluetooth** — статус/тогглы; заряд BT-устройств читается (см. §6).
- [ ] **Apple Events** — тёмная тема / Night Shift тогглы; первый раз спрашивает.
- [ ] **Пароль администратора** — только при установке демона (венты/заряд); отмена не ломает состояние.

## 4. Мониторинг — читается верно
- [ ] Кольцо заряда: % совпадает с системным; зарядка/от сети/от батареи отражаются.
- [ ] **Схема питания (flow)**: адаптер↔система↔батарея, ватты разумные; **анимация при вкл/выкл адаптера** плавная, без рывков высоты.
- [ ] **Железо**: температуры (CPU реальная по ядрам, не залипает), вентиляторы (обороты, бейдж «ручной режим» при форсе), нагрузка CPU/RAM, ватты компонентов.
  - **Apple Silicon (M-series)**: MacBook Air показывает **пассивное охлаждение** (нет ошибки «датчики не найдены»); доступные температуры отображаются из подтверждённого маппинга; неизвестные ключи остаются сырыми.
  - **Intel Mac**: CPU/GPU/battery температуры не регрессировали; fan RPM и ручной режим работают; перегрев использует правильный CPU-датчик.
- [ ] **Сеть**: ↓/↑ скорость ловит реальный трафик; локальный IP верный; **публичный IP НЕ запрашивается** (проверить отсутствие исходящих — Little Snitch/`nettop`).
- [ ] **Диск**: свободно/занято совпадает с Finder; ↓R ↑W реагирует на реальную дисковую активность.
- [ ] **Bluetooth-заряд**: подключённые AirPods (L/R/кейс) и Magic-устройства показывают %; отключённые исчезают (не залипают); не-Apple устройства не показываются.
- [ ] Строка меню: режимы Батарея/CPU/RAM; доп-показатели (watts/cputemp/gputemp/fan/cpu/ram/net/clock/date/diskio/diskfree/btbatt) — ширина **стабильна**, не дёргается на смене значений.
- [ ] **Combined-вид**: один блок с hairline-разделителями; **иконки параметров** тинтуются в свет/тьму; ширина не прыгает.
- [ ] Графики (поповер): оси/потолок адекватны; высота обеих вкладок равна (фикс-инвариант).
- [ ] **Диагностика SMC**: запуск `BM_SMCPROBE` выводит модель, архитектуру, статус SMC, resolved сенсоры с confidence и топологию охлаждения; отчёт объясняет отсутствие датчиков.

## 5. Уведомления — пороги
- [ ] Перегрев CPU / низкий заряд (деф. вкл) реально срабатывают баннером при пересечении порога.
- [ ] Антиспам: не чаще раза в 10 мин; короткий пик не триггерит (нужна устойчивость ~30с).
- [ ] Низкий заряд считается только от батареи; «заряжена» — только от адаптера.

## 6. Управление — ⚠️ ТРЕБУЕТ РЕАЛЬНОГО ЖЕЛЕЗА (демон, root)
> Эти пункты невозможно проверить в dev-сборке без установки демона. Проверять осознанно на тестовой машине.

- [ ] **Установка демона**: Настройки→Венты/Заряд→включить → диалог пароля → `kelvin-fand` ставится и стартует. Отмена пароля → состояние не сломано.
- [ ] **Вентиляторы**: профили Авто/Тихий/Баланс/Турбо/именованные — обороты реально меняются; защита по перегреву форсит максимум; «Авто» возвращает системный режим.
- [ ] **Именованные fan-пресеты**: создать/переименовать/дублировать/удалить; удаление применённого → авто; миграция старого «Свой» сработала.
- [ ] **Лимит заряда**: BCLM реально кепит на 80/75/70/60% (проверить, что заряд останавливается).
- [ ] **AlDente-режимы (на железе!):**
  - [ ] **Парусный** — заряжает до верхнего, держит, при работе от батареи проседает к нижнему, потом дозаряжает. (Помнить: BCLM не форсит разряд — просадка только при использовании.)
  - [ ] **Защита от перегрева** — при нагреве батареи (TB0T ≥ порога) заряд встаёт на паузу; остыла → возобновился.
  - [ ] **Top-Up** — «зарядить до 100% сейчас» снимает лимит ~на час, потом режим возвращается сам.
- [ ] **Безопасность демона**: убить app (Force Quit) → через lease-окно (15 мин) демон сам возвращает BCLM=100 и авто-венты (заряд/венты не залипают навсегда).
- [ ] **Деинсталляция демона**: отключение → пароль → демон удалён, системный режим возвращён.
- [ ] Фаервол, переключение языка/раскладки, сниппеты, свои кнопки-команды, переключение GPU и блок подключений работают без лицензии и апселла.

## 7. Таймеры (Free, после #5)
- [ ] Таймерный caffeine: 15м/1ч/2ч/до HH:MM — Mac реально не засыпает; по истечении — отпускает; **краш app не оставляет вечный assertion** (OS-timeout backstop).
- [ ] Sleep-таймер: «уснуть через N мин» срабатывает; отменяется; «погасить экран» работает.

## 8. Бесплатный доступ / апдейты
- [ ] На чистой установке все функции доступны сразу; нет экрана активации, триала или апселла.
- [ ] Раздел «Поддержать автора» честно сообщает, что донат доброволен и не открывает функции.
- [ ] **Апдейтер**: проверка `trykelvin.com/appcast.xml` не чаще раза в сутки; новая версия предлагается.
- [ ] **Автоязык**: runtime-статус отображается в настройках; диагностика `BM_LANGTEST` объясняет причину неработающего автоязыка.

## 9. Приватность (соответствие privacy.html)
- [ ] Снять трафик (Little Snitch/`nettop`) за сессию: из штатных запросов исходит только `trykelvin.com` (апдейт); проверок лицензии нет.
- [ ] Буфер обмена (история) не покидает Mac.
- [ ] **Отчёты о сбоях (если включены)**: проверить, что отправка требует явного согласия (по умолчанию выключена); preview показывает содержимое до отправки; один crash не отправляется дважды; payload не содержит имён пользователей, путей, лицензионных ключей, email.

## 10. Crash Reporting
- [ ] Искусственный DEBUG-crash (через меню или kill -SEGV) создаёт отчёт.
- [ ] Следующий запуск показывает карточку с уведомлением о падении.
- [ ] Кнопка «Посмотреть» открывает preview с санитизированным содержимым.
- [ ] Кнопка «Отправить» отправляет отчёт (требуется сеть).
- [ ] Кнопка «Не отправлять» удаляет отчёт без повторных вопросов.
- [ ] Автоматическая отправка работает **только** если включена в настройках приватности.
- [ ] Отклонённый crash не появляется повторно после перезапуска.
- [ ] Отправленный crash помечается как sent и не отправляется снова.
- [ ] Payload проходит golden tests на отсутствие PII (юнит-тесты).
- [ ] Breadcrumbs показывают последние события (без пользовательских данных).

## 11. Деинсталляция / чистота
- [ ] Удаление app + `uninstall-app.sh` убирает демоны, LaunchAgents, не оставляет форс-состояний SMC (BCLM=100, венты-авто).
- [ ] После удаления нет осиротевших процессов/плистов.
- [ ] Локальные crash reports и очередь отправки очищаются.

---

### Перед публичным релизом — обязательно «зелёное»:
1. Нотаризация Accepted + fresh-install на чистом Mac (§1).
2. Чистая установка показывает бесплатный доступ ко всем функциям (§8).
3. **M-series дамп battery-ключей** (`BatteryReader` на Apple Silicon помечен непроверенным — крупнейший сегмент).
4. Реальные тогглы/венты/фаервол/заряд-режимы на железе (§6).
5. **SensorResolver QA**: MacBook Air M1 не показывает отсутствие вентилятора как ошибку; доступные температуры из подтверждённого маппинга; неизвестные ключи сырые; все потребители используют один resolver.
6. **Автоязык QA**: runtime-статус виден в UI и отчёте; `BM_LANGTEST` объясняет причину неработающего автоязыка; нет пользовательского текста в логах.
7. **Диагностика**: отчёт объясняет выбор и отсутствие датчиков; не делает сетевых запросов; не содержит идентификаторов устройства.
