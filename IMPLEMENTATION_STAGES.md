## Definition of Done

Работа считается завершённой, когда одновременно выполнено следующее:

- [ ] MacBook Air M1 не показывает отсутствие вентилятора как ошибку

- [ ] Диагностический отчёт объясняет выбор и отсутствие датчиков
- [ ] Диагностический отчёт объясняет фактический статус автоязыка
- [ ] Нет требований менять системные загрузочные настройки
- [ ] Проходят unit-тесты, i18n-проверка и сборка

## Вопросы, которые нельзя решать догадкой

Если данных нет, агент должен остановить соответствующую часть реализации и запросить факты:

1. **Реальный обезличенный SMC-дамп MacBook Air M1** — требуется для заполнения fixture
2. **Какие ключи меняются синхронно с нагрузкой CPU/GPU** — требует эмпирической проверки
3. **Какие ключи подтверждены как батарейные** — требует эмпирической проверки
4. **Фактический вывод `FNum`** на M1 Air — требует проверки
5. **Для автоязыка:**
   - `AXIsProcessTrusted` — требует проверки на реальном устройстве
   - Результат создания event tap — требует проверки
   - Сохранённый и фактический режим — требует проверки
   - Список input source IDs — требует проверки
   - Состояние Pro/trial — требует проверки

**Без этих данных запрещено:**
- Назначать случайный `sp78` главным CPU/GPU-датчиком
- Менять пороги эвристики автоязыка
- Утверждать, что вентилятор отсутствует на конкретной модели
