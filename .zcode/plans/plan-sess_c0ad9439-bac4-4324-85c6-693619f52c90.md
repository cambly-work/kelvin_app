Canvas 660×400pt; окно `{200,120,860,520}`; иконка app на `{165,200}`, Applications на `{495,200}`, icon size 110. Фон — только подложка, Finder кладёт иконки поверх. Светящиеся платформы центрируем на x=165 и x=495, по вертикали на `ay = H*0.46` (=184 в y-up), как у существующей стрелки.

## 1. `tools/makedmgbg.swift` — новый рендер

Палитра (как в иконке): teal `#33C7D1`, blue `#2A86F0`, orange `#FF8E42`, red `#F5463D`.

**Слои (снизу вверх):**

1. **Базовый фон** — вертикальный градиент `#0A1428` → `#0E2A4A` (тёмно-синий, не чисто чёрный).
2. **Инфракрасные блобы** — 2–3 радиальных пятна по углам, сильно размытые, низкая альфа (0.15–0.25): тёплый оранжево-красный снизу-слева (как «раскалённое железо»), холодный бирюзовый сверху-справа. Через `NSGraphicsContext`/радиальные градиенты (`CGContext.drawRadialGradient` или составные `NSImage` с blur).
3. **Светящиеся платформы под иконками** — 2 мягких эллиптических свечения (бирюзово-синий радиальный градиент, яркий центр → прозрачный край), центрированы на `{165, ay}` и `{495, ay}`. Эффект «парения».
4. **Стрелка-трек** — пунктирная линия (точки/тире) teal→blue градиентом + лёгкое свечение (glow через `NSShadow` или двойной stroke: широкий полупрозрачный под низ, узкий яркий сверху), от x=250 до x=405 на `ay`, с аккуратной стрелкой-наконечником.
5. **Типографика (английский):**
   - «Kelvin» — ~30pt bold, белый, x=48, y=H-64
   - «Drag Kelvin to your Applications folder» — ~14pt medium, светло-серый (`#B8C5D6`), x=48, y=H-90
   - Подвал мелко/приглушённо (`#5A6B80`): «trykelvin.com» слева (x=48, y=24), версия справа (например `v0.9.0` читается из аргумента/по умолчанию — пока статично или из `CFBundleShortVersionString` не тянем, оставим чисто визуально «v0.9.0» или опустим версию, см. примечание).
   - Тонкая брендовая полоса teal→blue в самом верху (4px) —保留 из старого дизайна, хорошо читается на тёмном.

**Аргументы** оставить прежними: `<выходной путь> [scale=1]`. Скрипт уже вызывается для 1x и 2x.

**Реализация свечения/blur:** без внешних зависимостей — через многослойные радиальные градиенты (`CGGradient` с alpha) и/или приём «нарисовать в offscreen NSImage, потом растянуть несколько раз с пониженной alpha» для дешёвого blur. Glow стрелки — через `ctx.saveGraphicsState` + полупрозрачный широкий stroke до основного stroke.

## 2. `make-dmg.sh` — стилизация по умолчанию

Сейчас: `if [ "$STYLE_DMG" = "1" ]`. Меняем на инверсию: стилизация выполняется всегда, **кроме** случая `STYLE_DMG=0`.

```bash
# было (строка 42):
if [ "$STYLE_DMG" = "1" ]; then
# стало:
if [ "$STYLE_DMG" != "0" ]; then
```
Обновить комментарий в шапке (строки 3–4) чтобы отразить новое дефолтное поведение. Сам блок osascript и раскладка иконок НЕ меняются — координаты остаются корректными.

## 3. Перегенерация артефактов

```bash
swift tools/makedmgbg.swift Resources/dmg-bg.png 1
swift tools/makedmgbg.swift Resources/dmg-bg@2x.png 2
```
Затем опционально пересобрать DMG для визуальной проверки:
```bash
./build.sh && ./make-dmg.sh
```
Открыть `Kelvin-*.dmg` и убедиться, что фон, платформы и стрелка выровнены с иконками. При необходимости подкрутить координаты платформ/стрелки.

## Что НЕ делаем (YAGNI)
- Не вводим `create-dmg` или внешние тулзы — остаёмся на `hdiutil` + Finder/AppleScript.
- Не трогаем `release.sh`, `build.sh`, иконку приложения (`makeicon.swift`), volume icon.
- Не добавляем лицензионное окно / welcome screen / pkg-инсталлер — только фон DMG.
- Версию в подвале: если потянуть из PlistBuddy на этапе рендера лишняя сложность (скрипт рендера не знает про собранное приложение) — оставим «trykelvin.com» без версии или со статичной подписью. Уточню при реализации.
