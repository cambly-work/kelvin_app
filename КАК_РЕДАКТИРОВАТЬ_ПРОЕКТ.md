> Этот файл — карта проекта. Здесь описано, какой файл за что отвечает,
> где искать дизайн, логику автопереключения и всё остальное.

---

## 📁 Общая структура проекта

Проект **не использует Xcode** — сборка идёт через шелл-скрипт `build.sh`.
Все UI рисуются **программно** (без storyboard/xib). Нет SPM, CocoaPods и прочих зависимостей.

```
BatteryMeter/
├── Sources/          ← ВСЯ логика приложения (77 Swift-файлов)
├── Resources/        ← Иконки, GeoIP-базы, фон для DMG
├── helper/           ← Root-хелперы (fan daemon, powerd, hosts blocker)
├── test/             ← Юнит-тесты
├── tools/            ← Утилиты для генерации иконок
├── docs/             ← Сайт, EULA, Privacy, appcast.json
├── build.sh          ← Сборка приложения
├── Info.plist        ← Метаданные (имя, права, версии)
└── Kelvin.entitlements ← Разрешения для hardened runtime
```

## 🎨 Если хочешь изменить ДИЗАЙН

### Центральный файл дизайн-системы → `Sources/Design.swift`

Это **ЕДИНСТВЕННЫЙ файл**, где определены ВСЕ цвета, шрифты, отступы, радиусы, анимации.

| Что хочешь поменять | Что менять в `Design.swift` |
|---|---|
| Основной цвет акцента | `accent()`, `accentBright()`, `accentDeep()` — сейчас teal `#33C7D1` |
| Цвета предупреждений | `levelOK`, `levelWarn`, `levelCrit` |
| Цвета батареи (заряд) | Палитра в `chargeColor(level:)` |
| Шрифты и размеры текста | Функции `display()` … `microStat()` |
| Отступы между элементами | `Space` — сетка 4pt (`s1`=4, `s2`=8, `s3`=12, `s4`=16, `s5`=20, `s6`=24, `s7`=32) |
| Скругления кнопок/карточек | `Radius` — `tile`=16, `group`=12, `control`=10, `chip`=8, `pill`=7 |
| Скорость анимаций | `Motion` — `durFast`=0.18s, `durBase`=0.22s, `durSlow`=0.42s |
| Тени карточек | `Elevation.tileShadow` |

Настройки живут в **`Sources/Settings.swift`** (~4400 строк).

## ⌨️ Если хочешь починить АВТОПЕРЕКЛЮЧЕНИЕ (Punto Switcher)

Автопереключение раскладки — это **4 файла**:

| Файл | За что отвечает |
|---|---|
| **`Sources/LangSwitcher.swift`** | Главный мозг. CGEventTap ловит нажатия клавиш. Буферизует слово. По хоткею (Right Option) или автоматически при пробеле — вызывает конвертацию. Проверяет парольные поля. Переключает раскладку через TISSelectInputSource |
| **`Sources/LangDetect.swift`** | Эвристика: определяет, что слово набрано не в той раскладке. Считает долю гласных в текущей и «перевёрнутой» раскладке. Работает консервативно — лучше промолчать, чем ошибиться |
| **`Sources/LayoutMap.swift`** | Таблица соответствия клавиш EN↔RU (QWERTY↔YCUKEN). Функция `flip(word:)` переводит символы |
| **`Sources/InputSources.swift`** | Работа с раскладками через Text Input Source Services (TIS): получение списка, переключение |
| **`Sources/SpellFix.swift`** | Автоисправление опечаток (опционально, при пробеле) |
| **`Sources/FeedbackHUD.swift`** | Всплывающая подсказка при переключении раскладки |

### Частые проблемы с автопереключением:

| Симптом | Где искать |
|---|---|
| Не работает вообще | `LangSwitcher.swift` — проверь, создаётся ли CGEventTap. Нужно разрешение Accessibility (Системные настройки → Конфиденциальность → Доступность) |
| Переключает неправильно | `LangDetect.swift` — пороги эвристики (`0.08` / `0.15` / `0.25`). Если слишком агрессивно/пассивно — меняй эти числа |
| Не переключает раскладку системы | `LangSwitcher.swift` — `TISSelectInputSource`. Проверь, что нужная раскладка установлена в системе (`InputSources.swift`) |
| Не срабатывает хоткей | `LangSwitcher.swift` — ищи обработку `.flagsChanged` и проверь, что ловится Right Option (keyCode 0x3E) |
| Конфликт с парольными полями | `LangSwitcher.swift` — поиск `kCGEventTapOptionListenOnly` и логика пропуска Secure Input |
| Сниппеты не работают | `LangSwitcher.swift` — блок обработки сниппетов при word boundary |
| Не переключает обратно | `LayoutMap.swift` — проверь `flip(word:)` и `target(for:)` — возможно, маппинг не покрывает нужные символы |
